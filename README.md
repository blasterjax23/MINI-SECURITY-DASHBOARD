# 🛡️ Mini Security Dashboard

A simple **full-stack cybersecurity dashboard** built to demonstrate basic security monitoring concepts through a web-based interface.

## 📌 About the Project

The **Mini Security Dashboard** is a lightweight security-focused web application designed to provide a simple interface for experimenting with and understanding basic cybersecurity concepts.

The project uses a **Python Flask backend**, a web-based frontend, and a **SQLite database** for storing application data.

## 🚀 Features

* 🛡️ Security dashboard interface
* 🌐 Web-based frontend
* ⚙️ Flask/Python backend
* 💾 SQLite database integration
* 📊 Security-related data visualization/monitoring
* 🧪 Basic application testing
* 📱 Simple and responsive UI

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/blasterjax23/MINI-SECURITY-DASHBOARD.git
```

### 2. Enter the project directory

```bash
cd MINI-SECURITY-DASHBOARD
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Running the Application

Start the Flask application:

```bash
python app.py
```

The application will normally be available at:

```text
http://127.0.0.1:5000
```

Open the address in your browser to access the dashboard.

## 🧪 Running Tests

To run the available tests:

```bash
python test_app.py
```
